À propos de Seek It

Seek It est un moteur d'investigation téléphonique. Il recoupe opérateurs, plages de numérotation, bases publiques et fuites documentées pour dresser une carte des entités liées à un numéro.

Comment ça marche

Saisis un numéro (avec ou sans indicatif). Seek It affiche une carte centrale puis déploie les entités autour : opérateur, statut, localisation, ligne, appareil, entités liées.

Manipulation

  • Clic-glisser sur une carte : la déplacer
  • Glisser dans le vide : déplacer la vue
  • Molette : zoomer / dézoomer
  • Arbre / Radial : réorganiser automatiquement

Confidentialité

Aucune recherche n'est stockée côté serveur. Tout se passe localement.

Paramètres

À propos

Seek It est un moteur de recherche local qui interroge les sources ajoutées par les administrateurs.

Recherche

  • Prénom + nom séparés par un espace
  • Adresse email complète
  • Numéro de téléphone

Index ULP

Les entrées sont indexées localement dans votre navigateur. Cet index permet des recherches quasi-instantanées même sur de gros volumes.

Confidentialité

Aucune donnée n'est envoyée sur un serveur. Tout le traitement se fait dans votre navigateur.

Cookies et stockage local

Aucun cookie tiers. Aucun pixel de tracking. Aucun outil d'analyse externe. Le site utilise uniquement le stockage local du navigateur (localStorage / IndexedDB) pour vos préférences et les données importées par les administrateurs.

À propos

Seek It est un moteur de recherche local qui interroge les sources ajoutées par les administrateurs.

Recherche

  • Prénom + nom séparés par un espace
  • Adresse email complète
  • Numéro de téléphone

Index ULP

Les entrées sont indexées localement dans votre navigateur. Cet index permet des recherches quasi-instantanées même sur de gros volumes.

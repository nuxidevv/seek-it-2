À propos de Seek It

Seek It est un moteur de recherche qui interroge les databases ajoutées par l'administrateur.

Comment rechercher

  • Prénom + Nom : séparés par un espace
  • Email : adresse complète
  • Téléphone : avec ou sans indicatif

Utilise les Filtres avancés pour affiner par ville, code postal, département, pays, adresse, année de naissance ou genre.

Confidentialité

Aucune donnée n'est stockée sur nos serveurs. Les recherches sont anonymes.

1. Upload de fichiers

Glisse tes fichiers ici
ou clique pour parcourir — accepte .json, .txt, .csv, .sql, .ndjson
Formats acceptés :
• .json : tableau d'objets [{"prenom":"Jean",...}]
• .ndjson : un objet JSON par ligne
• .csv : avec en-tête (prenom, nom_famille, email…)
• .txt / .log : une entrée par ligne, champs séparés par :, | ou ;
• .sql : tuples ('Jean','Dupont','jean@…',…) extraits automatiquement
